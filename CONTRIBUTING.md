# Contributing

Bug reports, documentation corrections, and carefully scoped localization improvements are welcome via [Issues](https://github.com/AnlionGamer/MHP3rd-DLC-English-Localizer/issues) and pull requests.

Please keep changes **save-safe and reversible**:

- Never upload game ISOs, original downloadable DLC containers, character save files, or private reports.
- Avoid changing quest gameplay data, monster settings, rewards, equipment, hunter progression, or unknown/custom Palico text.
- Preserve original fullwidth Latin typography where specified in [NAME_TRANSLATION_POLICY.md](NAME_TRANSLATION_POLICY.md).
- Document translation provenance and credit; see [THIRD_PARTY_TRANSLATION_RIGHTS.md](THIRD_PARTY_TRANSLATION_RIGHTS.md).
- For code changes, describe the affected record types and relevant tests. The v1.0.0 tag remains the historical release baseline.
- Keep developer build artifacts outside the end-user ZIP.

See [docs/BUILDING.md](docs/BUILDING.md) and [docs/TESTING.md](docs/TESTING.md).
