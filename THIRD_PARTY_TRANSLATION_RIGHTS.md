# Translation provenance and public redistribution review

**Important public redistribution requirement.** The English quest-text catalog was developed to match the 6.3.0 TeamMaverickOne-era MHP3rd English patch vocabulary and wording for 65 recognized DLC quests, with an independently drafted translation for another quest. Palico names and Meowster romanizations have their own documented editorial policy. The source code's GPLv3 license is not permission to redistribute translations written by other people or copyrighted game text.

Before publishing a downloadable public EXE containing `catalog.json`, request written permission where the catalog contains contributed TMO-derived translated prose, or replace those entries with independently written/appropriately licensed text and revalidate the whole binary-integrity suite. Attribute all translators and reviewers as agreed. Also consider the relevant game copyright/terms; never embed an ISO or unmodified DLC save data in this application release.
