# MHP3rd DLC English Localizer v1.0.0 — Release Notes

Windows x64 standalone English-localization utility for **already-downloaded** Monster Hunter Portable 3rd DLC used with PPSSPP. This is an unofficial fan-made tool.

## What the release includes

- **MHP3rd_DLC_Localizer.exe:** Guided Find Saves → Choose DLC → Review & Apply interface.
- **MHP3rd_Recovery.exe:** Independent utility to recover from an interrupted direct installation.
- User instructions, recovery instructions, license and third-party translation rights notice.

## Supported localization

- Up to **66 recognized DLC quest** texts, without adding missing quests.
- Recognized existing promotional Palicoes: names, comments and Meowster creator names.
- Optional safe text updates for recognized already-recruited promotional Palicoes.
- Preserved original fullwidth Latin lettering and punctuation where present.
- Preserved quest gameplay data, character statistics, inventories and unrelated saves.

## Safeguards

- Encrypted and unencrypted PPSSPP saves supported.
- Explicit preview of proposed changes before applying them.
- Verified original backup and recoverable interrupted installations.
- No game ISO or DLC files bundled; does not download or install missing DLC.
- No Python installation required for Windows end users.
